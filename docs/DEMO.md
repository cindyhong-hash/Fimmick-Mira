# DEMO 流程 — marketing-tool（按製作順序）

> 給 report / 現場 demo 用。照順序行就由「素材 → 生成 → 圖庫管理」一條龍。
> ⚠️ #4 系列圖（固定模板）報告期間**已收起**（`SHOW_SERIES_TEMPLATE=false`），唔會喺 demo 出現。
> 開場：`npm run dev` → http://localhost:3000/library

---

## 0. 入場
- 開 `/library`，左欄揀一個**客戶資料夾**（例：舒適牌 Lady's Talk）。
- 一句介紹：「社群行銷素材工具，核心係素材庫：**風格組件** + **生成圖片** 兩個 tab。」

## 1. 風格組件 tab（素材底）
- **圖庫 filter**：📎參考圖 / 🌄背景 / 🧑人像 / 🎨插畫 / 🟣產品成圖 —— 一眼睇晒所有素材，每格有類型 + AI 引擎標籤。
- **上傳參考圖**：上傳客戶舊廣告 → AI 自動分析出 構圖 / 配色 / 語氣（可「調整」一次改）。
- **素材生成**：分 背景 / 人像（預設亞裔台港）/ 插畫（Recraft）三類，一次 1–5 張揀，可 ✨潤色描述、可放參考風格圖。

## 2. 生成圖片 tab —（A）產品圖合成【主菜】
1. **上傳產品圖**（全幅拖放，可 1–3 件）→ AI 自動讀圖填「主體」。
2. 揀**風格積木**（構圖 / 配色 / 背景）或一鍵套**行業範本**。
3. **合成方式**：**FLUX.2 edit（主力）** 中文字最清 / nano-banana 最自然 / Seedream 4.5。
4. **生成數量 1–5**：出多張揀（揀邊張先入圖庫）。
5. 撳生成 → 出圖 + **繁體中文文案**（主標/副標/CTA）。
6. 打開結果 popup → 展示「**來源產品圖**」（睇返用咗邊張）、下載 / 調整 / **移到其他客戶** / 刪除。
- **賣點**：產品上嘅**中文字保真**（FLUX.2 edit）、餵高清原圖、來源可追溯。

## 3. 生成圖片 tab —（B）文字主體 + ✨潤色
1. 切「文字主體（AI 生成）」→ 手寫短指令（例：「夏日防曬，海邊，清爽」）。
2. 撳 **✨潤色** → AI 擴寫成完整繁中設計描述（可再編輯）。
3. 生成 → 純 AI 場景圖 + 文案。
- **賣點**：唔識寫 prompt 嘅同事都用到；潤色會讀埋背景。

## 4. 圖庫管理
- 各 filter 切換睇分類；popup 下載 / 調整 / **移到其他客戶 / 設公用**（同一素材跨品牌重用）。
