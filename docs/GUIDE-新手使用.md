# 新手使用指南 — 社群行銷素材工具

> 俾第一次用呢個工具嘅人睇。由開機到生成第一張圖，一步步跟住做。
> 環境/安裝細節睇 [SETUP.md](./SETUP.md)；換機睇 [MIGRATION.md](./MIGRATION.md)。

---

## 0. 呢個工具係做咩？

幫你**快速整社群行銷圖文**。核心係**素材庫** `/library`，分兩個分頁：

- **風格組件**：你品牌嘅圖庫（上傳參考圖 / AI 生成背景），AI 會抽出「構圖 / 配色 / 語氣」素材。
- **生成圖片**：用「積木組合台」砌設定 → 生成新圖（純 AI 生成，或上傳產品圖做 AI 合成）。

---

## 1. 開機

1. 開 terminal，去專案資料夾，`npm run dev`。
2. 開瀏覽器去 **http://localhost:3000/library**。
（第一次載入要等 compile，可能 10 秒。）

---

## 2. 揀客戶

左欄「客戶資料夾」揀一個客戶（或「全部」）。客戶喺 `/clients` 頁新增。

## 3. 兩種生成方式

### A. 上傳產品圖做合成（最常用）
1. 「生成圖片」分頁 → 主體物件揀 **產品圖（合成用原圖）**。
2. 撳「加產品圖」上傳（**最多 3 件**，無需自己去背，AI 會去）。
3. （可選）風格積木揀 **背景**：撳開選一張背景圖。
4. 揀 **合成方式**：
   - **自然合成（nano-banana）** ← 預設，最自然、可多產品。
   - **保留文字（Bria）** ← 產品標籤/中文要清楚就揀呢個（**限 1 件產品**）。
   - **GPT-5.4 image** ← 測試用。
5. 揀 **輸出尺寸**（正方形 1200×1200 / 橫向 1800×1200）。
6. 撳「**合成產品圖到背景**」。等 10–60 秒。

### B. 純文字生成（冇產品圖）
1. 主體物件揀 **文字主體（AI 生成）**，打主體（例：夏日防曬面膜）。
2. 揀風格積木（構圖 / 配色 / 語氣）—— 喺「風格組件」分頁撳「帶入生成」帶入，或喺組合台直接揀。
3. 撳「**用此 Prompt 生成新圖**」。

> 生成完會喺下面「**圖片紀錄**」出現。點圖開 popup 可：下載 / 調整（改構圖配色語氣）/ 刪除 / 改標題 / 重新生成。

---

## 4. 風格組件分頁可以做咩

- **圖庫**：所有圖（🟢 上傳 / 🟣 AI生成 / 🟠 背景），每張顯示尺寸 + 引擎標籤（Nano Banana / Bria…）。點圖 → popup 睇構圖/配色/語氣，可「帶入生成」或「重新生成/調整」。
- **加入素材**：上傳參考圖 → AI 讀圖填構圖/配色/語氣（可逐項用「AI 生成此項」單獨重生成）→ 儲存。
- **背景生成**：打描述 → 生成純背景圖（無人/無文字/無產品），保留做合成底圖。
- **素材生成**：獨立生成背景/人像/插畫素材，詳見下方第 4a 節。

### 4a. 素材生成（背景 / 人像 / 插畫）

撳「素材生成」按鈕開啟面板，流程：

1. **揀素材類型**：背景（FLUX.1）/ 人像（FLUX.2 pro）/ 插畫（Recraft V3）。
2. **參考風格圖**（選填）：
   - 貼網址或上傳圖片 → AI 自動讀圖填描述初稿（20–30 字）。
   - 描述已有內容時，AI 不自動覆蓋；要強制重讀可按「**重新讀圖**」（藍色循環箭頭按鈕）。
3. **揀生成引擎**：
   - 預設（FLUX/Recraft，各類型對應不同引擎）：只靠文字描述生圖。
   - **Nano Banana**（需有參考圖）：以參考圖的色調/光影/質感做風格遷移，生全新畫面。
4. **描述**：填寫或修改 AI 初稿。
   - 「**潤色**」：AI 擴寫描述，100字內，有參考圖時融入風格；描述為空時自動先讀圖再潤色（一鍵搞定）。
5. 調整數量、尺寸 → 「**生成**」→ 點選要保留的圖 → 「**保留並儲存**」。
6. 生成完畢後可按「**重新生成/調整**」重改描述或參考圖再試。

## 5. ⚠️ AI 限制（一定要知，唔係 bug）

1. **產品/包裝上嘅中文字會走樣** —— AI 合成（nano-banana / GPT）係**重畫**成張圖，中文小字會扭曲。
   - 要文字清楚 → 揀「**保留文字（Bria）**」（佢保留你產品原相，唔重畫）。
2. **源圖太細/低清，出嚟一定糊** —— AI 加唔到原本冇嘅細節（垃圾入垃圾出）。請用**高清產品相**。
3. **斜面/弧面產品嘅標籤** —— 冇可靠方法重造；靠 Bria 保留原相（角度天生正確）。
4. **GPT-5.4 image 時快時慢** —— provider 不穩，可能等到 60 秒先轉用 nano-banana。日常用 nano / Bria 穩陣。
5. **3 件產品 + 背景** —— 背景會自動變「文字參考」（唔當圖片），因為太多圖會搞亂模型。
6. **生成要錢/時間** —— 每次合成會 call 付費 API（fal/OpenRouter），唔好亂試太多。

## 6. 常見情況點揀

| 你想 | 點做 |
|---|---|
| 產品擺入靚場景、最自然 | 自然合成（nano-banana）|
| 產品標籤/中文要睇得清 | 保留文字（Bria）、單件產品 |
| 多件產品一齊出 | 自然合成（nano-banana）|
| 純氛圍圖、冇實物 | 文字主體（AI 生成）|
| 只要一張乾淨背景 | 背景生成 |

詳細各引擎差異 → [AI-ENGINES.md](./AI-ENGINES.md)。

---

## 7. 撞到問題

| 問題 | 點算 |
|---|---|
| 文字走樣 | 揀 Bria 保留文字；或換高清產品相 |
| 合成等好耐 | 多數係揀咗 GPT（不穩）；改用 nano-banana |
| 出圖唔似揀嘅背景 | nano-banana 係參考唔係原樣；要原樣背景靠 Bria/疊圖 |
| 圖庫圖唔見更新 | 編輯後會自動 refresh；必要時 reload 頁 |
| API key / model 錯 | 睇 [SETUP.md](./SETUP.md) 嘅 `.env.local` 設定 |
